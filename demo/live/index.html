Press Run both. The two sessions take turns on one GPU: a Per-role LoRA turn, then a RoleKV turn.

Per-role LoRA A2

A standard LoRA per role. The cache is computed with one role's weights, so every role switch re-reads the whole context.

RoleKV A5-H1

Activated LoRAs: both roles share one base-model KV cache. A switch computes only the new tokens and re-reads the last reply.

  • computed this turn
  • reused from the KV cache
  • last reply re-read with base weights (handoff)
  • written by the role

Tokens computed = prefill + handoff re-read, every token run through the model outside decoding. Switch time to first token = mean over turns after the first, i.e. after a role switch. Time on GPU = sum of turn times, decoding included (decoding dominates a session). Comparisons use the turns both columns have finished.

Cost is an estimate: time on GPU × the GPU price above, which is an assumption, not a measured bill.
