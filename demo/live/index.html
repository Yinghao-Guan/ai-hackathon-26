The live demo needs its model server

This page runs both methods on a real model, turn by turn, so it has to be opened from demo/live/server.py. From the repository root:

uv run python demo/live/server.py \
  --model Qwen/Qwen2.5-Coder-1.5B-Instruct --adapters adapters/1.5b

then open http://127.0.0.1:8001/. Without the trained adapters, demo/README.md (Live demo) shows how to make throwaway ones on a laptop.

RoleKV A5-H1

An Activated LoRA per role: both roles share one base-model KV cache, so a switch computes only the new tokens.

Each turn appears here as the server sends it.

Tokens computed = prefill + handoff re-read: every token run through the model outside decoding. Time to first token after a switch = mean over the turns after the first. Time on GPU = sum of turn times, decoding included. Comparisons use the turns both sides have finished. Cost is an estimate: time on GPU × the GPU price above, an assumption, not a measured bill.
